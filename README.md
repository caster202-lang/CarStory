# 차계부 앱 프로젝트 — 카스토리(CarStory)

바이브 코딩으로 만드는 차계부(자동차 관리) 앱 프로젝트 폴더입니다.
수입차 브랜드별 교체 주기 안내가 강점이고, 국산차도 함께 지원합니다.

## 폴더 구성

- **차계부-앱-와이어프레임.html**
  초기 저충실도 와이어프레임 (홈/소모품/주유/통계 화면 레이아웃 스케치). 브라우저로 열어서 확인 가능.

- **index.html**
  실제로 동작하는 MVP 웹앱 (앱 본체). GitHub Pages에서 바로 열리도록 `index.html` 이름을 씁니다. **HTML 파일 하나**라서 브라우저로 더블클릭하면 바로 실행됩니다.
  (아직 PWA는 아닙니다. 홈 화면 설치·기기 푸시 알림을 쓰려면 manifest + 서비스워커 추가가 필요합니다.)

## 쓰기 전에 꼭 알아둘 것 — 데이터 저장 위치

기록은 **열어본 그 브라우저 안(localStorage)에만** 저장됩니다. 그래서:

- 같은 브라우저로 열어야 이전 기록이 보입니다
- 브라우저 캐시/사이트 데이터를 지우면 **기록이 사라집니다**
- 시크릿 모드에서는 창을 닫는 순간 사라집니다

👉 **차량 탭 → 데이터 백업 → 내보내기** 로 가끔 JSON 파일을 저장해두세요.
기기를 바꾸거나 실수로 지웠을 때 **불러오기**로 그대로 되살릴 수 있습니다.

한 번도 백업하지 않았거나 마지막 백업이 30일을 넘으면 **홈 맨 위에 안내 줄**이 뜹니다.
누르면 바로 차량 탭으로 넘어가요.

## 주요 기능

**차량**
- 브랜드(국산 5 · 수입 32) · 모델 · **유종**(가솔린/디젤/하이브리드/전기/LPG) · 연식 · 주행거리
- 홈 차량 카드에 브랜드 색 이름표. 등록한 브랜드 색이 앱 포인트 색이 됩니다
- 전기차는 브랜드 또는 유종으로 알아봅니다 (BMW i4 · 아이오닉5 같은 차도 인식)

**소모품 (26종)**
- 유종에 맞는 항목만 목록에 보입니다. 전기차엔 엔진오일·점화플러그가 안 나옵니다
- 기본 주기는 국내 정비 기준표를 따릅니다 (엔진오일 1만km, 필터류 1만km, 배터리 3년 등)
- 종류별 아이콘·색, 남은 수명 게이지 (막 교체 100% → 다 쓰면 0%, 빈 칸이 붉게)
- 주행거리와 날짜 중 먼저 오는 쪽으로 판정: 양호 / 곧 교체(남은 10% 이하 또는 1,500km·30일) / 시기 지남
- 교체 주기가 없는 항목(언더코팅 등)은 "언제 했는지"만 표시
- **오늘 교체** 버튼으로 날짜·주행거리를 한 번에 입력
- **교체 비용**과 **메모**(브랜드·제품명·정비소) 기록. 교체할 때마다 이력이 쌓입니다
- **같이 교체한 항목**을 한 번에 기록. 엔진오일을 고르면 오일필터가 자동 체크됩니다
  (교체 주기가 있는 항목만 후보로 나옵니다)
- 소모품 탭 아래 **교체 이력**에서 지난 교체를 최신순으로 보고 한 줄씩 지울 수 있습니다.
  날짜는 그대로 두고 금액만 고치면 이력이 새로 생기지 않고 그 줄의 금액이 바뀝니다
- 타이어: 교체 / 교체(앞) / 교체(뒤) / 위치교환을 나눠 관리

**브랜드별 기준**
- 엔진오일·오일필터를 등록하면 *제조사 공식 주기*와 *국내 실주행 권장 주기*를 나란히 보여주고 고를 수 있습니다
- 37개 브랜드 중 28개에 기준이 들어 있습니다
- 2026-09-16에 수입 브랜드 9개 그룹을 재조사해 **쉐보레·캐딜락·GMC·뷰익, 푸조·시트로엥, 닛산·인피니티** 세 그룹의
  주기를 바로잡았습니다 (셋 다 실제보다 늦게 교체를 권하고 있었습니다).
  미니만 아직 확정하지 못해 참고값 문구가 남아 있습니다

**튜닝 (8종)**
- 오픈흡기 필터 · ECU 맵핑 · 브레이크 킷 · 서스펜션 · 휠·타이어 · 다운파이프 · 머플러 · 인터쿨러
- 대부분 주기가 없어 기록만 남고, 소모품 주기에 영향을 주는 경우 안내가 뜹니다
  (예: 오픈흡기 필터는 교체가 아니라 5,000km마다 세척)

**주유 / 충전**
- 전기차면 "충전 · kWh · 전비(km/kWh)"로 화면의 말이 모두 바뀝니다
- 가득 주유(완전 충전) 구간으로 연비를 계산해서 부분 주유가 섞여도 정확합니다

**그래프**
- 홈: 월별 유지비 (주유비 + 교체비, 최근 6개월)
- 주유 탭: 연비(전비) 추이

**그 밖에**
- 내 차 상태 **인쇄 / PDF 저장** — 정비소용 · 중고차 판매용 · 보관용을 한 장에
- 밝은 화면 / 어두운 화면 전환
- JSON 백업 내보내기 · 불러오기 (형식 3판 — 나중에 여러 대를 담을 수 있게 차량 id를 미리 붙여 내보냅니다.
  예전에 내보낸 파일도 그대로 불러와집니다)
- 유종별 예시 데이터 넣어보기

## 이어서 작업할 때

Claude Code나 Claude Cowork에서 이 폴더를 열어서 작업을 이어가시면 됩니다.
`index.html` 파일이 실제 앱 코드이며, 여기에 기능을 추가/수정하면 됩니다.

기존 코드 구조(화면별 렌더 함수 + localStorage 데이터 계층)를 유지하면서 확장하는 걸 권장합니다.

**코드 고친 뒤 확인하는 법**: 브라우저 주소 끝에 `?test`를 붙여서 열면
(예: `index.html?test`) 교체 시기·연비 계산이 맞는지 자동으로 검사하고,
개발자도구 콘솔(F12)에 "selfTest 통과"가 찍힙니다. 문제가 있으면 빨간 에러가 납니다.
